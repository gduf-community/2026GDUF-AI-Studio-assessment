# 沪深300 五日收益预测

## 一、赛题背景

量化研究需要在每个交易日收盘后对股票池做出判断。本题以沪深300为固定股票池，要求参赛者在 T 日收盘后预测未来一周的相对强弱，并直接给出一个可评分的持仓组合。

赛题只涉及横截面选股，不涉及交易执行、组合优化，也不构成投资建议。

## 二、任务

- **股票池**：沪深300成分股 300 只，以 `universe.csv` 为准，不得增删或替换。
- **决策时点**：T = 2026-12-04 收盘后。只能使用截至 T 日收盘可得的行情。
- **测试窗口**：T+1 至 T+5，即 2026-12-07 至 2026-12-11。
- **持仓约束**：最多选 5 只股票；每只权重非负；权重合计为 1。
- **个股收益**：`open(T+5) / open(T+1) - 1`，即 T+1 开盘买入、T+5 开盘卖出。
- **组合收益**：`score = Σ weight_i × return_i`，测试窗口结束后统一计算。
- **提交次数**：每支队伍只提交一次，提交后不能根据测试窗口行情调整。

## 三、数据

主办方提供冻结快照 `hs300_snapshot_20261204.zip`，解压后 data/ 目录包含（字段名见文件表头）：

| 文件 | 说明 |
| --- | --- |
| `train.csv.gz` | 300 只成分股日线，后复权 |
| `universe.csv` | 股票池，300 只 |
| `index.csv` | 沪深300指数日线 |
| `calendar.csv` | 交易日列表 |
| `meta.json` | 来源、复权方式、截止日 |

数据说明：

- 区间为 2018-01-02 至 2026-12-04，价格已后复权，停牌日无记录。
- 快照已在 T 日收盘后冻结，不含 T 之后的价格。
- 可补充公开数据（行业、财务），但须截至 T 日可得、可复现，并说明来源；禁止付费数据、券商数据及测试窗口信息。

## 四、提交内容

### 1. Docker 镜像

提交 `docker save` 导出的 tar（如 `team01.tar`）。评测时：

- 数据快照挂载到 `/app/data`（只读），输出目录挂载到 `/app/output`（可写）；
- 容器在无网络环境下启动，入口自行指定，结束后读取 `/app/output/result.csv`；
- 全部计算在容器内完成，不得依赖外部服务；
- 参考资源 8 小时、16 GB 内存、10 核 CPU；镜像需支持 linux/amd64，超时或报错视为无效。

### 2. 代码仓库

包含数据读取、清洗、特征、训练、预测与评分脚本，附依赖版本、运行命令与随机种子。仓库中不得包含真值文件或任何可还原真值的文件。

### 3. 结果文件

`result.csv` 使用 UTF-8 编码，两列，1–5 行。要求：股票代码为 6 位字符串、保留前导零、不得重复；权重非负且合计为 1；不得有空值；股票须来自股票池。

```csv
stock_id,weight
300433,0.4
002558,0.3
301236,0.3
```

### 4. 项目结果报告

不超过 2 页，说明数据口径、验证方案、特征与模型、回测结果、风险与局限。

## 五、评测

- **主指标**：测试窗口组合收益，越高越好。
- **辅助指标**：组合相对 300 只股票等权平均的超额收益。
- **排名**：按组合收益从高到低；同分时比较超额收益。
- **综合评定**：单期只持有 5 只股票，结果受个股事件影响很大，最终成绩同时参考滚动回测、代码质量与报告，避免单周运气决定名次。
- **无效提交**：文件格式不合规、代码重复或不在股票池、权重为负或合计不等于 1、容器超时或未生成结果、使用测试窗口信息、结果无法复现。

## 六、规则与边界

- 禁止针对测试股票池手工指定预测或硬编码结果。
- 结果须可复现；抽查不一致按未提交处理。
- 本题仅用于算法能力考核，所有预测不构成投资建议。

参考仓库：gduf-community/2026GDUF-AI-Studio-assessment
